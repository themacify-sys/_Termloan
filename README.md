# Term Loan - Official Enterprise Website

This repository contains the complete responsive static web applications for **Term Loan** (Udyam Reg: `UDYAM-UP-29-0257019`).

## 🚀 How to Deploy on GitHub Pages
1. Push all files to your GitHub Repository root directory.
2. Go to **Repository Settings** -> **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live instantly!
